# Lessons for KOML

The domain needs explicit separation of routine activity from meaningful change. Counts alone do not establish progress: a setback and a milestone are both meaningful entries, and a period comparison cannot establish causation.

Synthetic tests validate the assumption that explicit significance flags permit exact deterministic classification. The independent oracle plants 80 meaningful IDs among 200 records. Mutation tests show counts respond to input changes. The assumption that Henry will actually use this tool remains unvalidated until a real trial.

Operating rule for future builds: define the human judgement field and its limits before adding automation, then test against an independent oracle and an input mutation. Never convert an unmeasured usefulness claim into a reported saving.
